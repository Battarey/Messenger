# Gateway Service (API Gateway)

Сервис является единой точкой входа для всех внешних HTTP и WebSocket запросов клиентов к бэкенду мессенджера Eta.

**Основные задачи:**
- Маршрутизация запросов к соответствующим внутренним микросервисам.
- Валидация JWT-токенов (Auth Offloading) с передачей идентификатора пользователя во внутренние сервисы в заголовках.
- Ограничение частоты запросов (Rate Limiting).
