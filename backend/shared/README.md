# Shared Library (Общая библиотека)

Пакет содержит общий переиспользуемый код, разделяемый между всеми микросервисами.

**Содержимое библиотеки:**
- Базовые схемы Pydantic и конфигурационные классы.
- Общие утилиты для логирования, обработки ошибок и валидации.
- Общие клиенты для работы с внешними сервисами (базы данных, Redis, очереди задач).
