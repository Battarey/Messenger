# Connection Service (Сервис WebSockets)

Сервис поддерживает постоянные WebSocket-соединения с клиентами и обеспечивает доставку сообщений в реальном времени.

**Основные задачи:**
- Удержание WebSocket-подключений активных пользователей.
- Подписка на Redis Pub/Sub для маршрутизации сообщений и событий между инстансами бэкенда.
- Обработка heartbeat-запросов (пинг/понг) от клиентов для отслеживания статуса присутствия (online/offline).
