# Settings Service (Сервис настроек)

Сервис отвечает за хранение и синхронизацию пользовательских предпочтений и параметров приватности.

**Основные задачи:**
- Сохранение настроек оформления интерфейса (выбранная тема, язык).
- Управление матрицами приватности (кому отображать статус online, био и т.д.).
- Ведение списков исключений для настроек приватности.
