# Chat Service (Сервис чатов и сообщений)

Сервис отвечает за создание чатов, ведение переписки и хранение истории сообщений.

**Основные задачи:**
- Управление личными (one-to-one) и групповыми чатами (создание, удаление, списки участников).
- Отправка, редактирование и удаление сообщений (поддержка текста, медиа-вложений, гео-точек).
- Отслеживание статуса прочтения сообщений и хранение истории переписки.
- Публикация событий в Outbox-таблицу для асинхронного захвата (CDC).
