# Media Service (Сервис медиа и хранения файлов)

Сервис предназначен для безопасной загрузки, обработки и предоставления доступа к медиа-файлам пользователей.

**Основные задачи:**
- Загрузка, валидация типов и размеров вложений (аватары, файлы в чатах).
- Оптимизация изображений и генерация превью-изображений.
- Интеграция с S3-хранилищем и выдача временных безопасных Signed URLs для скачивания контента.
