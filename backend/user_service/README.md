# User Service (Сервис профилей пользователей)

Сервис управляет персональными данными пользователей и информацией их публичных профилей.

**Основные задачи:**
- Ведение профилей пользователей (уникальный логин `@username`, отображаемое имя, био, ссылка на аватар).
- Поиск пользователей по их никнеймам.
- Интеграция с другими сервисами для обновления связанных данных о пользователях.
