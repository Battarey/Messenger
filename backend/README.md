# Backend для мессенджера "Eta"

## Архитектура backend

- **[auth_service](./auth_service)** — **Сервис аутентификации и авторизации**
  * *Зоны ответственности:* Passwordless-вход по OTP-кодам и magic-links, генерация/обновление JWT-токенов (`Access`, `Refresh`), привязка дополнительных email-адресов, инициация сессий входа по QR-коду.

- **[chat_service](./chat_service)** — **Сервис управления чатами и сообщениями**
  * *Зоны ответственности:* Создание и удаление личных и групповых чатов, добавление участников, хранение истории сообщений (текст, геолокация, ссылки на вложения).
  
- **[connection_service](./connection_service)** — **Сервис WebSockets (Real-time)**
  * *Зоны ответственности:* Удержание постоянных соединений с клиентами, трансляция событий и сообщений пользователям через Redis Pub/Sub, отслеживание статуса присутствия (*presence*) по heartbeat.
  
- **[contact_service](./contact_service)** — **Сервис списка контактов**
  * *Зоны ответственности:* Управление контактами пользователя, добавление в друзья, ведение списков блокировок (черный список).
  
- **[gateway_service](./gateway_service/)** — **API Gateway**
  * *Зоны ответственности:* Единая точка входа для HTTP-трафика, маршрутизация запросов к конкретным микросервисам, валидация JWT-токенов (Auth Offloading), Rate Limiting и SSL-терминация.
  
- **[media_service](./media_service)** — **Сервис медиа и хранения файлов**
  * *Зоны ответственности:* Загрузка и валидация файлов (аватары, картинки, документы), сжатие и генерация превью, выдача временных безопасных Signed URL для скачивания.
  
- **[migrations](./migrations/)** — **Миграции баз данных**
  * *Зоны ответственности:* Централизованное управление схемами реляционных баз данных для всех сервисов.
  
- **[notification_service](./notification_service/)** — **Сервис асинхронных уведомлений**
  * *Зоны ответственности:* Асинхронная отправка Email (OTP-коды, ссылки безопасности) и отправка мобильных/десктопных Push-уведомлений (через Firebase FCM / Apple APNs).
  
- **[settings_service](./settings_service)** — **Сервис пользовательских настроек**
  * *Зоны ответственности:* Синхронизация настроек интерфейса (тема, язык) и хранение матриц приватности пользователей (кому виден статус online, описание и т.д.).
  
- **[shared](./shared)** — **Общая библиотека**
  * *Зоны ответственности:* Повторно используемый код: базовые схемы Pydantic, конфигурационные классы настроек, утилиты логирования, декораторы валидации и обработчики ошибок.
  
- **[tests](./tests)** — **Интеграционные тесты**
  * *Зоны ответственности:* Тестирование межсервисного взаимодействия и проверка работоспособности всего API в Docker.
  
- **[user_service](./user_service)** — **Сервис профилей пользователей**
  * *Зоны ответственности:* CRUD профилей пользователей (аватары, уникальные логины `@username`, отображаемые имена, текстовое описание профиля).
