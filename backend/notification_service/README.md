# Notification Service (Сервис асинхронных уведомлений)

Сервис отвечает за доставку уведомлений пользователям по внешним каналам связи.

**Основные задачи:**
- Отправка транзакционных Email (OTP-коды, ссылки для входа) через фоновые задачи ARQ.
- Отправка Push-уведомлений (Firebase FCM / Apple APNs) при получении новых сообщений, когда пользователь находится не в сети.
