# Auth Service (Сервис аутентификации)

Сервис отвечает за регистрацию, аутентификацию пользователей и безопасность доступа к их аккаунтам.

**Основные задачи:**
- Аутентификация по одноразовым OTP-кодам (Email) и временным ссылкам (magic links).
- Реализация авторизации через QR-коды для десктоп/веб версий приложения.
- Выпуск, обновление и отзыв сессионных токенов (JWT Access/Refresh).
- Управление активными сессиями пользователей.
