# Миграции базы данных (Alembic)

В этой директории находятся файлы миграций базы данных PostgreSQL.

---

## Архитектура env.py

Скрипт `env.py` является точкой входа для Alembic. Поскольку проект использует асинхронный драйвер базы данных (`asyncpg`), выполнение миграций разделено на три ключевые функции:

### 1. `run_migrations_offline()`
* **Назначение:** Запуск в автономном (offline) режиме без подключения к реальной базе данных.
* **Как работает:** Вызывается при передаче флага `--sql` (например, `alembic upgrade head --sql`). Alembic считывает метаданные моделей в памяти и генерирует готовый файл с SQL-скриптом (DDL) для ручного выполнения.

### 2. `run_migrations_online()`
* **Назначение:** Точка входа для наката миграций на реальную базу данных.
* **Как работает:** Создает асинхронный движок SQLAlchemy (`create_async_engine`) на основе `POSTGRES_URL` из настроек, открывает соединение и передает выполнение в синхронный контекст Alembic с помощью специального метода `connection.run_sync()`.

### 3. `do_run_migrations(connection)`
* **Назначение:** Непосредственное выполнение транзакции миграции.
* **Как работает:** Внутренний механизм применения миграций в Alembic работает в синхронном режиме. Эта функция вызывается внутри `run_sync`. 
  * Перед началом миграций функция выполняет SQL-запрос `CREATE SCHEMA IF NOT EXISTS ...` для автоматического создания логических схем (`users`, `chats`, `contacts`, `read_models`).
  * После этого открывается транзакция и накатываются файлы миграций из папки `versions`.

## Основные команды

Все команды должны запускаться из директории `backend/` с использованием Poetry:

* **Создание новой миграции (автогенерация на основе моделей):**
  ```bash
  poetry run alembic revision --autogenerate -m "описание_изменений"
  ```
  *(Примечание: Убедитесь, что база данных запущена в Docker, так как Alembic сверяет текущую структуру БД с кодом моделей).*

* **Применение всех миграций (обновление БД до последней версии):**
  ```bash
  poetry run alembic upgrade head
  ```

* **Откат последней миграции:**
  ```bash
  poetry run alembic downgrade -1
  ```

* **Просмотр истории миграций:**
  ```bash
  poetry run alembic history
  ```
