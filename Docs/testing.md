# Тестирование

## Подход

Для тестирования бэкенда используется фреймворк **Pytest** с поддержкой асинхронности через плагин `pytest-asyncio`.

### Пирамида тестирования
1. **Unit-тесты (Модульные):** Тестируют изолированную логику (например, чистые функции, валидаторы схем Pydantic). Они должны быть быстрыми и выполняться без обращения к реальным БД или внешним API (с использованием mock-объектов при необходимости).

## Правила написания тестов

### Паттерн AAA (Arrange-Act-Assert)
Все тесты должны быть написаны с помощью паттерна AAA.

### Правила именования
- Все файлы с тестами должны начинаться с префикса `test_` (например, `test_auth_flow.py`).
- Все тестовые функции должны начинаться с префикса `test_` (например, `test_login_success()`).
- Имена тестовых функций должны отражать конкретное действие и ожидаемый результат (например, `test_register_user_with_existing_email_fails`).
