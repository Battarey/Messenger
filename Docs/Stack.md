## Backend

* **Язык:** Python 3.12
* **Фреймворк:** FastAPI
* **Валидация и конфигурация:** 
  * Pydantic v2 для строгой валидации и сериализации данных схемы API
  * Pydantic-settings для управления конфигурацией через переменные окружения
* **Работа с базами данных:**
  * **ORM:** SQLAlchemy 2.0
  * **Миграции:** Alembic 
* **Фоновые задачи (Background Worker):** 
  * **ARQ:** Полностью асинхронная и легковесная очередь задач на базе Redis
* **Управление зависимостями:** Poetry
* **Качество кода и линтинг:**
  * **Ruff:** Статический анализ и форматирование кода
  * **Vulture:** Обнаружение мертвого кода
  * **Deptry:** Проверка импортов на соответствие зависимостям
  * **pre-commit:** [Будет описан когда будет реализован]
* **Тестирование:** Pytest


## Databases

* **Основная СУБД:** PostgreSQL
* **Зоны ответственности:**
  * Хранение учетных записей пользователей, профилей и настроек.
  * Хранение структуры чатов (личные, групповые) и истории сообщений.
  * Таблица событий (Outbox) для надежной отправки сообщений через брокер (Transactional Outbox Pattern).


## Message Broker & Caching

* **Решение:** Redis 7.2+ (in-memory база данных).
* **Зоны ответственности:**
  * **WebSocket Pub/Sub:** Распределение и маршрутизация сообщений в реальном времени между инстансами бэкенда.
  * **Кеширование:** Хранение кэша пользовательских профилей и статусов активности ("онлайн/офлайн").
  * **Сессии:** Быстрое хранение и валидация токенов авторизации.
  * **Очередь задач:** Брокер для фоновых асинхронных задач (например, отправка кодов подтверждения на почту).


## DevOps & Observability (Инфраструктура и мониторинг)

* **Docker:** Multi-stage сборки Dockerfile отдельно для бэкенда и фронтенда (минимизация размера образов и изоляция сборок).
* **Локальная оркестрация:** Docker Compose (база данных, Redis, бэкенд, фронтенд и мониторинг в едином виртуальном контуре).
* **Стек Наблюдаемости (Observability):**
  * **Метрики:** Prometheus (сбор метрик производительности FastAPI приложения через `prometheus-fastapi-instrumentator`).
  * **Логирование:** Grafana Loki + Promtail (сбор логов всех Docker-контейнеров без записи в файлы на диске бэкенда).
  * **Трассировка:** OpenTelemetry (для отслеживания пути запроса от API до базы данных).
  * **Визуализация:** Grafana (дашборды для мониторинга ресурсов, ошибок и задержек).
