# Базы данных

## PostgreSQL

* **Зоны ответственности:**
  * Учетные записи пользователей, регистрационные данные и настройки безопасности.
  * Структура чатов (личные/групповые) и связи между участниками.
  * История сообщений (с использованием гибких JSONB-полей для вложений).
  * Списки контактов, настройки приватности и черные списки.
  * Поток изменений WAL (Change Data Capture через Logical Replication) для надежной WebSocket-рассылки и обновления витрин чтения без дополнительной нагрузки на диск.

## Архитектурный паттерн: WAL CDC & CQRS

Для обеспечения максимальной производительности на чтение и снижения нагрузки на запись в проекте используется связка **Change Data Capture (CDC)** на базе **WAL** и селективный **CQRS**:

1. **Запись (Write Model):** API-сервис записывает транзакционные данные (новые сообщения, чаты) в нормализованные таблицы схем `users`, `chats`, `contacts`.
2. **Захват изменений (CDC):** Легковесный асинхронный Python-сервис (WAL listener) подключается к слоту логической репликации PostgreSQL и читает системный лог транзакций Write-Ahead Log (WAL) в реальном времени.
3. **Обновление витрин (Read Model):** При появлении события добавления сообщения listener:
   * Публикует событие в **Redis Pub/Sub** для доставки клиентам по WebSocket.
   * Асинхронно обновляет денормализованную таблицу `read_models.user_chats_list` (для мгновенного рендеринга списка чатов у пользователей).


## Redis
**Роль:** Обеспечение работы WebSocket в реальном времени, кэширование горячих данных и движок фоновых задач.

* **Зоны ответственности:**
  * **WebSocket Pub/Sub:** Распределение сообщений между параллельными инстансами бэкенда для доставки сообщений пользователям в реальном времени.
  * **Статусы активности (Presence):** Мгновенная фиксация статусов «онлайн/офлайн» пользователей в оперативной памяти с автоматическим TTL (временем жизни ключа).
  * **Очередь задач (ARQ):** Хранилище задач для фонового асинхронного воркера (отправка email, очистка временных ссылок).
  * **Кэш сессий:** Быстрая проверка JWT-токенов авторизации для разгрузки PostgreSQL.
  * **Авторизация по QR-коду:** Временные короткоживущие токены `qr:{token_hash} -> account_id` с TTL 5 минут.
  * **Подтверждение Email:** Временные 6-значные коды подтверждения регистрации/входа `email_verify:{email} -> verification_code` с TTL 10 минут.
